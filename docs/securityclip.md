# Security Scope Compatibility Note

Security Scope is the current product name for the corpus retrieval tool that was previously documented as Securityclip.

The implementation package and legacy command names remain available for compatibility:

```bash
securityclip
securityclip-web
securityclip-mcp
```

Prefer the new command aliases in new docs and examples:

```bash
security-scope
security-scope-web
security-scope-mcp
```

Primary documentation now lives in:

- [Security Scope Guide](securityscope.md)
- [Architecture](securityscope_architecture.md)
- [Marlowe Operations](securityscope_marlowe.md)
- [Command Reference](securityscope_commands.md)
